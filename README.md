## The line

> My phone's battery dies at 4 p.m. sharp every day, like it's clocking out of a job it never applied for.

## How to run

Run `node main.ts` with Node 22. The program creates `/output` if needed and writes the line above, with no trailing newline, to `/output/entry.txt`.
